01 / THE THREE LAWS

三律

工坊的一切出品遵守三条铁律。它们不是隐私政策式的承诺，而是可以亲手验证的事实。

壹 第一律

绝对单机

数据即文件

所有数据存储为本地文件，备得了份、带得走。功能 100% 在本机完成——无账号、无激活服务器、无云依赖；导出走系统分享面板，发不发、发给谁，你说了算。

鸿蒙：应用内一键导出 JSON / CSV，经系统分享面板存到你指定的位置——全程零权限。Windows：数据目录就是一个普通文件夹，复制即备份。
贰 第二律

零网络权限

想联网也做不到

全系应用零网络权限申请。

权限申请清单 · 商店详情页可见
网络 INTERNET✕ 未申请
鸿蒙：应用市场详情页的「权限」列表里没有「网络」。Windows：断网后全功能照常，抓包出站为 0——四步图文见第 02 节。
叁 第三律

永久可用

停更即开源

已购版本永久可用、永久可重装：不设订阅、没有激活服务器，想远程失效也做不到。任一应用连续 12 个月无任何版本更新，30 天内开源全部自有源代码——MIT 协议，第三方组件按原协议附清单。

维护状态在下方「维护面板」随时公示；条款全文见第 06 节，并同步写入商店简介与应用内关于页——不因本站存亡而失效。
02 / VERIFY IT YOURSELF

别信我，去验证

隐私政策是承诺，权限列表是系统强制的事实。四个步骤，任何人都能亲手确认第二律。

鸿蒙手机 / 平板 HARMONYOS

应用市场详情页直接展示权限申请清单

  1. 打开华为应用市场，搜索任一守一应用
  2. 进入应用详情页，下拉找到「权限」
  3. 查看权限列表——没有「网络」
  4. 第二律成立：系统强制，应用无法绕过

Windows 电脑 WINDOWS

断网测试 + 抓包观察，双保险

  1. 防火墙出站规则中屏蔽该应用
  2. 全部功能照常使用——单机软件断网无损
  3. 或用 GlassWire / Wireshark 观察任意时长
  4. 出站请求数为 0（逐步图文教程随产品附上）

为什么「权限列表」比「隐私政策」可信

隐私政策是文本，写什么全凭自觉；权限列表由操作系统强制执行——一个没有网络权限的应用，连一个字节都发不出去。我把承诺放在系统管得住的地方。

抓 包 悬 赏

用任何抓包工具证明任一守一应用发出网络请求，赏金一千元。裁定标准只有三条，满足即付。真零联网，才有底气开门迎客。

一、请求归属于守一应用——以抓包工具显示的应用 / 进程为准（鸿蒙按 UID / 包名），系统服务与其他应用的流量不算；
二、提供完整可复现步骤：设备型号、系统版本、工具与配置、操作顺序；
三、写明捕获时间窗，可重复验证。

06 / GUARANTEE

开源保底条款

「我若停更，代码归你们。」你不需要相信我的意志力，只需要相信一条公开规则。

开源保底条款

OPEN-SOURCE FALLBACK CLAUSE · V1.1 · 2026-09

第一条

任一在售应用连续十二（12）个月未在应用商店发布任何更新版本，开发者将在三十（30）日内将该应用发布时的完整自有源代码，以 MIT 协议向公众开放；第三方组件按其原协议附清单一并公开。应用下架的，自下架之日起算连续十二（12）个月，同样触发——下架不免除本条款。「更新」以应用商店实际发布的任意版本为准——包括只修 Bug 的小版本。规则在此写明，不设隐藏条款。

第二条

停更应用仍在应用商店与官网持续提供下载，已购用户永久可重新安装，功能不受影响。

第三条

本条款对条款发布之日前后的全部应用一体生效，不经公告不得撤销或加严限制。

第四条

各应用维护状态于本站「维护面板」随时公示，公示本身即本条款的一部分。

第五条

本条款全文同步写入应用商店简介与应用内「关于」页，与官网具有同等效力——即使本站不可访问，条款依然可查、依然有效。

07 / ABOUT

关于工坊

守一工坊是一个人的软件工坊。守一，取自道家「守一存真」——老子所谓「圣人抱一为天下式」。守，是守护，也是守诺：数据只写在你自己的设备上，一分一毫不出门。一，是一台设备、一件小事、一个承诺——一生只做一件事，一人只守一个诺。

这里出品的每个工具：只解决一个问题、绝对单机、零网络权限、永久可用。克制比功能丰富更重要——用户已经有太多「什么都能做」的软件，缺的是打开就能用、用完就能忘的工具。

三律是工坊的宪法，写在上面，也写进每个应用的权限列表里。如果我哪天停更了，条款会替我履约：代码开源，工具永生。
